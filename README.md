# GeoWatch 2

GeoWatch 2 é um projeto desenvolvido em grupo inspirado no jogo GeoGuessr.

O objetivo do jogo é desafiar os jogadores a identificar locais ao redor do mundo a partir de imagens de ruas e paisagens, utilizando conhecimentos geográficos e observação de detalhes do ambiente.

Este projeto foi desenvolvido como atividade acadêmica, com foco no trabalho em equipe, planejamento e desenvolvimento de uma aplicação web interativa.

## Sobre o Projeto

O GeoWatch 2 busca proporcionar uma experiência divertida e educativa, incentivando os usuários a explorar diferentes regiões do mundo e testar seus conhecimentos de geografia.
